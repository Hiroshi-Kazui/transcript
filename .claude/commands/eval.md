# /eval

現在のパイプライン設定を `eval/golden/` の参照テキストと比較し、品質スコアを算出して `eval/EVAL.md` に追記する。
パラメータ変更後の採用判断はこのコマンドの結果のみで行う。「読んだ感じ良い」は判断基準にしない(CLAUDE.md鉄則)。

## 手順

1. `python eval/metrics.py` を実行し、以下を算出:
   - CER(golden基準との文字誤り率、3クリップ平均・個別)
   - 幻覚繰り返し率(n-gram重複検出)
   - VAD発話区間カバレッジ(取りこぼし検出)
   - 句読点密度(整形品質)
2. 直前の `/smoke` 実行結果を入力に使う(無ければ先に `/smoke` を促す)
3. 結果を `eval/EVAL.md` に追記: 日時・変更したパラメータ・各スコア・前回比較
4. スコアが悪化した場合は変更を破棄するかどうかユーザーに確認せず、悪化した旨と数値を報告するだけに留める(採用判断は実装者が行い、理由をEVAL.mdに書く)

## EVAL.md フォーマット

```
## 2026-07-10 14:32 — VAD閾値を0.5→0.35に変更
- CER: 0.082 → 0.061 (改善)
- 繰り返し率: 0.03 → 0.01 (改善)
- VADカバレッジ: 0.94 → 0.98 (改善)
- 採用: する
```

テキスト本文の引用はEVAL.mdに含めない(golden setの内容が漏れるため)。数値とパラメータのみ。
